Flecha's shortcuts work everywhere in the browser, before the page and Chromium's menus see the keys. Press <kbd>⌘</kbd><kbd>/</kbd> to open this list in Settings.

| --- | --- |

| Open location (command bar on the current tab) | <kbd>⌘</kbd><kbd>L</kbd> |
| Back | <kbd>⌘</kbd><kbd>[</kbd> |
| Forward | <kbd>⌘</kbd><kbd>]</kbd> |
| Reload | <kbd>⌘</kbd><kbd>R</kbd> |
| Hard reload | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>R</kbd> |
| Find in page | <kbd>⌘</kbd><kbd>F</kbd> |
| Show or hide the sidebar | <kbd>⌘</kbd><kbd>S</kbd> |

## Record your own shortcuts

Open Settings › **Keyboard Shortcuts** (<kbd>⌘</kbd><kbd>/</kbd>), click a shortcut and press the keys you want.

- <kbd>⌫</kbd> removes the shortcut and <kbd>Esc</kbd> cancels.
- A shortcut needs at least one of <kbd>⌘</kbd>, <kbd>⌃</kbd> or <kbd>⌥</kbd> with a key, or a function key on its own.
- <kbd>⌘</kbd> or <kbd>⌃</kbd> with a digit is kept for tabs and Spaces.
- If the keys already belong to another action, that action loses them and Flecha tells you which one.
- Each row has a button to go back to its default, and **Restore Defaults** resets them all.

Every action in the tables can be rebound. Going to a tab (<kbd>⌘</kbd><kbd>1</kbd>–<kbd>9</kbd>), going to a Space (<kbd>⌃</kbd><kbd>1</kbd>–<kbd>9</kbd>) and closing Peek (<kbd>Esc</kbd>) are fixed. A few keys that Chromium keeps for itself, such as <kbd>⌘</kbd><kbd>N</kbd> and <kbd>⌘</kbd><kbd>Q</kbd>, can't be recorded as new shortcuts.
