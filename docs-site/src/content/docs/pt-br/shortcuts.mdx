Os atalhos do Flecha funcionam no navegador inteiro, antes que a página e os menus do Chromium vejam as teclas. Aperte <kbd>⌘</kbd><kbd>/</kbd> para abrir esta lista nas Configurações. Os nomes das ações aparecem em inglês, como no app.

## Gravar seus próprios atalhos

Abra Configurações › **Keyboard Shortcuts** (<kbd>⌘</kbd><kbd>/</kbd>), clique num atalho e aperte as teclas que quiser.

- <kbd>⌫</kbd> remove o atalho e <kbd>Esc</kbd> cancela.
- Um atalho precisa de pelo menos um entre <kbd>⌘</kbd>, <kbd>⌃</kbd> ou <kbd>⌥</kbd> com uma tecla, ou de uma tecla de função sozinha.
- <kbd>⌘</kbd> ou <kbd>⌃</kbd> com um número fica reservado para abas e Spaces.
- Se as teclas já forem de outra ação, essa ação perde o atalho e o Flecha avisa qual foi.
- Cada linha tem um botão para voltar ao padrão, e **Restore Defaults** restaura todos.

Todas as ações das tabelas podem ser regravadas. Ir para uma aba (<kbd>⌘</kbd><kbd>1</kbd>–<kbd>9</kbd>), ir para um Space (<kbd>⌃</kbd><kbd>1</kbd>–<kbd>9</kbd>) e fechar o Peek (<kbd>Esc</kbd>) são fixos. Algumas teclas que o Chromium guarda para si, como <kbd>⌘</kbd><kbd>N</kbd> e <kbd>⌘</kbd><kbd>Q</kbd>, não podem ser gravadas como atalho novo.
