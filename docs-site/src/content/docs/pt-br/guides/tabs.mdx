A sidebar do Flecha tem três tipos de aba. O lugar onde a aba fica decide o que acontece quando você a fecha.

| | Onde | Ao fechar |
| --- | --- | --- |
| **Favoritos** | Os ícones no topo, iguais em todos os Spaces | Descarrega a aba e volta para o endereço salvo |
| **Abas fixadas** | Abaixo dos favoritos, por Space, com pastas | Descarrega a aba e volta para o endereço fixado |
| **Today** | A lista de baixo, por Space | Arquiva a aba |

O botão de fechar mostra **Unload tab** em favoritos e abas fixadas, e **Close tab** nas abas Today. Clicar com o botão do meio também fecha.

## Mover abas

Arraste uma aba:

- para a barra de favoritos, para virar favorito,
- para a lista de abas fixadas, ou para cima de uma pasta, para fixá-la,
- para Today, ou para cima de **New Tab**, para desafixá-la,
- para cima da página, para abri-la em [tela dividida (split view)](/docs/pt-br/guides/peek-split-flechinha/#tela-dividida).

Quando uma aba vira fixada ou favorito, o endereço atual dela passa a ser o endereço para onde ela volta. Se você navegou para longe, clique com o botão direito nela e escolha **Go Back to Pinned URL**.

## Pastas

- Crie uma com **New Folder** no menu de botão direito do Space. Ela entra no fim da lista de abas fixadas.
- Clique duas vezes no nome de uma pasta para renomeá-la. Clique uma vez para abrir ou fechar.
- Arraste abas para cima dela para guardá-las ali.
- Para apagar uma pasta, use Configurações › **Tabs & Spaces**. O Flecha pergunta se você quer manter as abas dela ou apagá-las também.

## Abas Today e o arquivo

Toda aba que você abre pela [barra de comandos](/docs/pt-br/command-bar/) começa em Today. As abas Today se arquivam sozinhas quando você passa um tempo sem usá-las:

- 12 horas por padrão; troque em Configurações › **Tabs** › **Archive Today tabs after** para 1 dia, 7 dias, 30 dias ou nunca,
- a aba que você está vendo nunca é arquivada,
- **Clear**, ao lado do título Today, ou <kbd>⇧</kbd><kbd>⌘</kbd><kbd>K</kbd>, arquiva na hora todas as abas Today deste Space.

O arquivo guarda as últimas 500 abas. Para encontrá-las, digite na barra de comandos: elas aparecem em **Archive**. <kbd>⇧</kbd><kbd>⌘</kbd><kbd>T</kbd> reabre a mais recente.

## O menu da aba

Clique com o botão direito numa aba para ver: **Open in Split View**, **Copy Link**, **Copy as Markdown Link**, **Rename…**, **Duplicate**, **Open in Flechinha**, **Pin Tab**, **Add to Favorites**, **Move to Space**, **Reload**, **Mute Tab**, **Go Back to Pinned URL** e **Close Tab**. As abas Today também têm **Close Tabs Below** e **Close Other Tabs**.

Os atalhos de tudo isso estão em [Atalhos de teclado](/docs/pt-br/shortcuts/#abas).
