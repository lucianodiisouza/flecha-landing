O [Dia](https://www.diabrowser.com/) é o navegador com IA da The Browser Company, e é para onde ela manda os usuários do Arc agora que [o Arc está sendo encerrado](https://arc.net/). O Flecha é um navegador open source que mantém a interface do Arc. Eles respondem a perguntas diferentes: o Dia coloca um assistente de IA no navegador; o Flecha mantém o navegador simples e deixa o seu próprio agente de código entrar quando você pede.

## Resumo

| | Flecha | Dia |
| --- | --- | --- |
| Feito por | OPrimoDev | The Browser Company (Atlassian) |
| Motor | Chromium | Chromium |
| Código | Open source, MIT | Código fechado |
| Plataformas | macOS | macOS, Windows |
| Preço | Grátis | Grátis; recursos de IA nos planos pagos ([preços](https://www.diabrowser.com/pricing)) |
| Conta | Nenhuma | Necessária para sync e IA |
| Sidebar | Sempre, no estilo do Arc | Layout opcional |
| Spaces | Spaces, com cookies separados se você quiser | Profiles |
| Peek | Sim | Não |
| Boosts | Sim | Não |
| Assistente de IA embutido | Não | Sim |
| Agentes de código externos | [Servidor MCP embutido](/docs/pt-br/agents/mcp/) | Não |
| Importa do Arc | Spaces, abas fixadas, pastas, favoritos, histórico | Spaces como Profiles, pastas como grupos de abas, senhas, histórico, extensões |
| Sync | Não | Com criptografia de ponta a ponta |

## Escolha o Dia se

- você quer um assistente de IA dentro do navegador, que lê suas abas e age nelas,
- você precisa de Windows ou de sync entre computadores,
- você quer trazer suas senhas do Arc.

## Escolha o Flecha se

- você quer a sidebar, o Peek e os Boosts do Arc como eram,
- você prefere não ter conta e que nada sobre você saia do seu Mac,
- você programa e quer uma [barra de comandos](/docs/pt-br/command-bar/) que entende `gh` e `npm`, uma tecla para ir entre local, staging e produção, e seus servidores de dev na sidebar,
- você já usa Claude Code ou Cursor e quer que eles vejam o seu navegador de verdade via [MCP](/docs/pt-br/agents/mcp/),
- você quer um navegador que não pode ser descontinuado: o código é público.

Quer testar? [Instale o Flecha](/docs/pt-br/install/) e [importe a sua sidebar do Arc](/docs/pt-br/switch-from-arc/).
