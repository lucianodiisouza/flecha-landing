O [Vivaldi](https://vivaldi.com/) é um dos navegadores que os usuários do Arc mais testam agora que [o Arc acaba em 22 de dezembro de 2026](/docs/pt-br/arc-shutdown/). Os dois são navegadores Chromium que deixam a IA generativa de fora. A diferença é de filosofia: o Vivaldi tem uma opção para quase tudo, e o Flecha copia a sidebar do Arc e para por aí.

## Resumo

| | Flecha | Vivaldi |
| --- | --- | --- |
| Feito por | OPrimoDev | Vivaldi Technologies |
| Motor | Chromium | Chromium |
| Plataformas | macOS 13+ (Apple silicon e Intel) | macOS 13+, Windows, Linux, Android, iOS ([download](https://vivaldi.com/download/)) |
| Abas verticais | Sidebar no estilo do Arc, sempre | Barra de abas em qualquer lado da janela ([ajuda](https://help.vivaldi.com/desktop/tabs/tab-bar/)) |
| Spaces | Spaces, com cookies e logins separados por padrão | [Workspaces](https://vivaldi.com/features/workspaces/) |
| Abas fixadas que voltam ao endereço, abas Today que se arquivam | Sim | Não |
| Peek e Little Arc | Peek e Flechinha | Não |
| Tela dividida | Dois painéis | [Tab tiling](https://help.vivaldi.com/article/tab-tiling/), várias páginas |
| Extensões | Chrome Web Store | Chrome Web Store |
| Login do Google | Sim | Sim |
| Bloqueio de anúncios e rastreadores | Embutido | Embutido |
| IA embutida | Nenhuma | Nenhuma, de propósito ([Vivaldi 7.8](https://vivaldi.com/blog/vivaldi-7-8-launches-with-message-to-big-tech-humans-dont-need-ai-babysitters/)) |
| Cliente de e-mail embutido | Não | Sim |
| Código | Open source, MIT | Mudanças no Chromium públicas, interface fechada |
| Preço | Grátis | Grátis |
| Netflix e outros serviços com DRM Widevine | Não; oferece abrir a página no Safari | Sim ([ajuda](https://help.vivaldi.com/desktop/media/widevinecdm-eme-drm-netflix-amazon-spotify/)) |
| Conta e sincronização | Sem conta, sem sincronização | Conta opcional, sincronização com criptografia de ponta a ponta |
| Importa os Spaces do Arc | Sim, com abas fixadas, pastas e favoritos | Não achamos importador do Arc |

## Escolha o Vivaldi se

- você precisa de Windows, Linux ou app de celular, ou de sincronização entre aparelhos,
- você assiste Netflix, Disney+ ou Spotify no navegador,
- você gosta de ajustar cada detalhe, das pilhas de abas ao lado onde fica a barra, e quer o e-mail na mesma janela.

## Escolha o Flecha se

- você quer a sidebar do Arc como era: favoritos, abas fixadas que voltam para onde começaram, abas Today que se arquivam sozinhas, Peek e Flechinha,
- você quer seus Spaces, abas fixadas e pastas do Arc [trazidos num passo só](/docs/pt-br/switch-from-arc/),
- você prefere menos opções e nenhuma conta,
- você faz sites e quer uma [barra de comandos para devs](/docs/pt-br/command-bar/) e um [servidor MCP embutido](/docs/pt-br/agents/mcp/) para agentes de código.

Quer testar? [Baixe o Flecha](https://flecha.dev/pt-br/#download) e [importe sua sidebar do Arc](/docs/pt-br/switch-from-arc/). Ainda decidindo? Veja [todas as alternativas ao Arc](/docs/pt-br/compare/arc-alternatives/).
