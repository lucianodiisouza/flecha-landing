O Flecha foi feito por um usuário do Arc, para manter a interface do Arc depois que [a The Browser Company encerrar o Arc](https://arc.net/) em **22 de dezembro de 2026**. Os dois são navegadores Chromium com sidebar vertical, então a maioria dos seus hábitos continua valendo. Esta página lista o que é igual e o que não é.

## O que é igual

- **Sidebar e Spaces.** Uma sidebar vertical com favoritos, abas fixadas com pastas e abas Today, em Spaces que você troca com <kbd>⌃</kbd><kbd>1</kbd>–<kbd>9</kbd> ou deslizando dois dedos.
- **As abas fixadas voltam.** Fechar uma aba fixada descarrega a aba e devolve ela ao endereço fixado.
- **As abas Today se arquivam sozinhas**, depois de 12 horas por padrão, e o arquivo é pesquisável.
- **Peek.** Links de abas fixadas e favoritos abrem num cartão flutuante.
- **Tela dividida (split view)**, duas páginas lado a lado.
- **Little Arc → Flechinha.** Links de outros apps abrem numa janela pequena.
- **Boosts.** Seu próprio CSS e seus scripts para qualquer site.
- **Extensões do Chrome** da Chrome Web Store.
- A maioria dos [atalhos de teclado](/docs/pt-br/shortcuts/) é igual: <kbd>⌘</kbd><kbd>T</kbd>, <kbd>⌘</kbd><kbd>S</kbd>, <kbd>⇧</kbd><kbd>⌘</kbd><kbd>C</kbd>, <kbd>⌘</kbd><kbd>D</kbd>.

## O que muda

| | Flecha | Arc |
| --- | --- | --- |
| Futuro | Open source (MIT), não pode ser desligado | Para de funcionar em 22 de dezembro de 2026 |
| Plataformas | macOS (Apple silicon e Intel) | macOS, Windows |
| Conta | Nenhuma | Obrigatória |
| Sync entre computadores | Não | Sim, até o encerramento |
| Perfis | Cookies e logins separados por Space | Profiles |
| Tela dividida | Dois painéis | Até quatro painéis |
| Boosts | TypeScript e CSS, editados no Flecha | Zap, CSS e JavaScript |
| Easels, Notes, Arc Max | Não | Sim |
| Ferramentas de desenvolvimento | [Barra de comandos](/docs/pt-br/command-bar/) com `gh`, `npm`, `mdn` e decodificação de JWT; local, staging e produção numa tecla; visão de celular; servidores de dev na sidebar | Não |
| Agentes de código | [Servidor MCP embutido](/docs/pt-br/agents/mcp/) para Claude Code, Cursor e outros | Não |
| Bloqueio de anúncios e rastreadores | Embutido (EasyList, EasyPrivacy) | Precisa de extensão |
| Telemetria | Nenhuma | Veja a [política de privacidade da The Browser Company](https://arc.net/privacy) |

## Como migrar

O Flecha [importa a sidebar do Arc](/docs/pt-br/switch-from-arc/): Spaces com nome e emoji, abas fixadas e pastas, abas não fixadas como abas Today, favoritos e histórico. Senhas, cookies, abas arquivadas, Easels e Boosts ficam para trás.

Faça isso antes de 22 de dezembro, enquanto o Arc ainda abre, para conferir lado a lado que nada ficou faltando.
