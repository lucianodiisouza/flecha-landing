O [Microsoft Edge](https://www.microsoft.com/edge) teve abas verticais anos antes da maioria dos navegadores, e roda no mesmo motor Chromium do Arc. Para quem está saindo do Arc, é a escolha conhecida e bem suportada. O Flecha é a opção menor e open source, que mantém a sidebar do Arc do jeito que os usuários do Arc conhecem.

## Resumo

| | Flecha | Edge |
| --- | --- | --- |
| Feito por | OPrimoDev | Microsoft |
| Motor | Chromium | Chromium |
| Plataformas | macOS 13+ (Apple silicon e Intel) | macOS 13+ ([Microsoft](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-supported-operating-systems)), Windows, Linux, Android, iOS |
| Abas verticais | Sidebar no estilo do Arc, sempre | Painel de abas verticais opcional ([Microsoft](https://www.microsoft.com/en-us/edge/learning-center/how-to-multitask-like-a-pro)) |
| Spaces | Spaces, com cookies e logins separados por padrão | Workspaces (conjuntos de abas numa janela própria) e perfis |
| Abas fixadas que voltam ao endereço, abas Today que se arquivam | Sim | Não |
| Peek e Little Arc | Peek e Flechinha | Não |
| Tela dividida | Dois painéis | Split screen, duas abas numa janela |
| Extensões | Chrome Web Store | Edge Add-ons e a Chrome Web Store |
| Login do Google | Sim | Sim |
| Bloqueio de anúncios e rastreadores | Embutido (EasyList, EasyPrivacy) | Prevenção de rastreamento embutida; anúncios pedem uma extensão |
| IA embutida | Nenhuma | Copilot, com recursos que dá para desligar ([Microsoft](https://blogs.windows.com/msedgedev/2026/05/13/new-updates-to-edge-across-desktop-and-mobile/)) |
| Código | Open source, MIT | Fechado, sobre o Chromium |
| Preço | Grátis | Grátis |
| Netflix e outros serviços com DRM Widevine | Não; oferece abrir a página no Safari | Sim; a Netflix lista o Edge como compatível no Mac ([Netflix](https://help.netflix.com/pt/node/23742)) |
| Conta e sincronização | Sem conta, sem sincronização | Conta Microsoft opcional para sincronizar |
| Importa os Spaces do Arc | Sim, com abas fixadas, pastas e favoritos | Não achamos importador do Arc |

## Escolha o Edge se

- você precisa de Windows, Linux, app de celular ou sincronização com uma conta Microsoft,
- você assiste Netflix, Disney+ ou Spotify no navegador,
- você quer o Copilot no navegador, ou a sua empresa gerencia o Edge para você.

## Escolha o Flecha se

- você quer a sidebar do Arc: favoritos, abas fixadas com pastas, abas Today que se arquivam sozinhas, Peek e Flechinha,
- você quer seus Spaces do Arc [importados num passo só](/docs/pt-br/switch-from-arc/),
- você prefere sem conta, sem telemetria e sem IA embutida,
- você faz sites e quer uma [barra de comandos para devs](/docs/pt-br/command-bar/) e um [servidor MCP embutido](/docs/pt-br/agents/mcp/).

Quer testar? [Baixe o Flecha](https://flecha.dev/pt-br/#download) e [importe sua sidebar do Arc](/docs/pt-br/switch-from-arc/). Ainda decidindo? Veja [todas as alternativas ao Arc](/docs/pt-br/compare/arc-alternatives/).
