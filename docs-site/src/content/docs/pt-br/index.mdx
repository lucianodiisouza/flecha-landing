O Flecha é um navegador Chromium gratuito e open source para macOS, feito para quem programa. Ele tem sidebar vertical com Spaces, uma barra de comandos que entende atalhos de dev e uma ponte MCP que deixa o seu agente de código ver e controlar as suas abas. Não tem conta nem telemetria: tudo fica no seu Mac.
