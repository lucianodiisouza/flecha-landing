## 0.1.0 — October 23, 2026

The first release of Flecha as a Chromium fork, for Apple silicon. The Intel build of 0.1.0 followed on October 24.

**Browser**
- Vertical sidebar with [favorites, pinned tabs, folders and Today tabs](/docs/guides/tabs/) that archive themselves.
- [Spaces](/docs/guides/spaces/), with optional separate cookies and logins per Space.
- [Peek, split view and Flechinha](/docs/guides/peek-split-flechinha/).
- Real Chromium: Chrome Web Store extensions and Google sign-in on sites work.
- Built-in [ad and tracker blocking](/docs/guides/privacy/#ad-and-tracker-blocking).
- Incognito windows with Flecha's frame.
- [Import](/docs/switch-from-arc/) from Arc, Chrome, Brave, Edge, Vivaldi, Opera, Firefox and Safari in the welcome tour.

**For developers**
- [Command bar](/docs/command-bar/) with `gh`, `npm`, `mdn`, `caniuse`, `so`, `env` and `boost`, and JWT and timestamp decoding.
- [Environments, responsive view, local dev servers and console error badges](/docs/guides/developer-tools/).
- [Boosts](/docs/guides/boosts/): your own TypeScript and CSS for any site.
- An [MCP server](/docs/agents/mcp/) for Claude Code, Cursor and other coding agents.

**Everything else**
- Re-recordable [keyboard shortcuts](/docs/shortcuts/).
- Signed, notarized builds with automatic updates through Sparkle.
