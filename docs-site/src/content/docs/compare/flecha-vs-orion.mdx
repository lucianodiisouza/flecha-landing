[Orion](https://orionbrowser.com/), by the search company Kagi, is a Mac browser that many Arc users look at for its privacy stance and its iPhone app. The biggest difference from Flecha is the engine: Orion is built on WebKit, like Safari, and Flecha on Chromium, like Arc. That decides how sites render, which extensions work and how familiar it feels after Arc.

## At a glance

| | Flecha | Orion |
| --- | --- | --- |
| Made by | OPrimoDev | Kagi |
| Engine | Chromium | WebKit |
| Platforms | macOS 13+ (Apple silicon and Intel) | macOS, iOS and iPadOS. Kagi stopped developing Orion for Linux and Windows in October 2026 ([AlternativeTo](https://alternativeto.net/news/2026/10/kagi-ends-development-of-orion-for-linux-and-windows-open-sources-code-to-community/)) |
| Vertical tabs | Arc-style sidebar, always | Optional vertical tabs ([Kagi](https://blog.kagi.com/orion-features)) |
| Spaces | Spaces, with separate cookies and logins by default | Profiles, each with its own cookies and extensions |
| Pinned tabs that return to their address, Today tabs that archive | Yes | No |
| Peek and Little Arc | Peek and Flechinha | No |
| Split view | Two panes | Not on Orion's feature list |
| Extensions | Chrome Web Store, as in Chrome | Many Chrome and Firefox extensions, with 20 that Kagi guarantees ([Orion](https://orionbrowser.com/)) |
| Ad and tracker blocking | Built in | Built in |
| Telemetry | None | None ([Orion](https://orionbrowser.com/)) |
| Built-in AI | None | No AI data collection, per Kagi |
| Source | Open source, MIT | Not open source on macOS |
| Price | Free | Free; Orion+ as a subscription or a lifetime license |
| Netflix and other Widevine DRM | No; offers to open the page in Safari | Not on Netflix's list of supported Mac browsers ([Netflix](https://help.netflix.com/en/node/23742)) |
| Imports from Arc | Spaces, pinned tabs, folders, favorites, history, cookies | Arc is one of its import sources ([Kagi](https://help.kagi.com/orion/getting-started/importing.html)) |

## Choose Orion if

- you want the same browser on your Mac, iPhone and iPad,
- you prefer WebKit, the engine Safari uses,
- you already use Kagi and like how it works.

## Choose Flecha if

- you want pages to render as in Chrome and every Chrome Web Store extension to work, not a subset,
- you want Arc's sidebar: Spaces, pinned tabs with folders, Today tabs that archive themselves, Peek and Flechinha,
- you want your Arc Spaces [imported with their pinned tabs and folders](/docs/switch-from-arc/),
- you want the code to be public, so the browser can't disappear the way Arc is,
- you build websites and want a [developer command bar](/docs/command-bar/) and a [built-in MCP server](/docs/agents/mcp/).
