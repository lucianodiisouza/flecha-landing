[Brave](https://brave.com/) is a privacy-focused Chromium browser with ad blocking on by default, and many people leaving Arc already know it. Both Brave and Flecha are open source and block ads and trackers out of the box. Brave has vertical tabs but not Arc's sidebar model; Flecha has Arc's sidebar but runs only on Macs.

## At a glance

| | Flecha | Brave |
| --- | --- | --- |
| Made by | OPrimoDev | Brave Software |
| Engine | Chromium | Chromium |
| Platforms | macOS 13+ (Apple silicon and Intel) | macOS, Windows, Linux, Android, iOS ([download](https://brave.com/download/)) |
| Vertical tabs | Arc-style sidebar, always | Optional vertical tab strip ([Brave](https://brave.com/blog/vertical-tabs/)) |
| Spaces | Spaces, with separate cookies and logins by default | Profiles and tab groups, no Spaces |
| Pinned tabs that return to their address, Today tabs that archive | Yes | No |
| Peek and Little Arc | Peek and Flechinha | No |
| Split view | Two panes | Yes ([Brave](https://brave.com/whats-new/tab-split-view)) |
| Extensions | Chrome Web Store | Chrome Web Store |
| Google sign-in | Yes | Yes |
| Ad and tracker blocking | Built in (EasyList, EasyPrivacy) | Built in (Brave Shields) |
| Built-in AI | None | Leo assistant |
| Crypto wallet, rewards, VPN | No | Built in, optional |
| Source | Open source, MIT | Open source, MPL-2.0 ([GitHub](https://github.com/brave/brave-browser)) |
| Price | Free | Free; Brave Origin, a build without Leo, Rewards, VPN and Wallet, is a one-time purchase on Mac and Windows ([Privacy Guides](https://www.privacyguides.org/news/2026/06/07/brave-launches-paid-minimalist-brave-origin-browser/)) |
| Netflix and other Widevine DRM | No; offers to open the page in Safari | Yes, after you turn Widevine on ([Brave help](https://support.brave.app/hc/en-us/articles/360023851591)) |
| Account and sync | No account, no sync | Sync between devices with a sync code |
| Imports Arc's Spaces | Yes, with pinned tabs, folders and favorites | No Arc importer we could find |

## Choose Brave if

- you need Windows, Linux or a phone app, or sync between devices,
- you watch DRM-protected streaming in the browser,
- you want an AI assistant available in the browser, or use Brave's other services.

## Choose Flecha if

- you want Arc's sidebar, not just vertical tabs: favorites, pinned tabs with folders, Today tabs that archive themselves, Spaces with their own logins, Peek and Flechinha,
- you want your Arc sidebar [imported in one step](/docs/switch-from-arc/),
- you want a browser with nothing extra in it: no AI, wallet, rewards or VPN,
- you build websites and want a [developer command bar](/docs/command-bar/) and a [built-in MCP server](/docs/agents/mcp/).

Ready to try? [Download Flecha](https://flecha.dev/#download) and [import your Arc sidebar](/docs/switch-from-arc/). Still deciding? See [all the Arc alternatives](/docs/compare/arc-alternatives/).
