[Vivaldi](https://vivaldi.com/) is one of the browsers Arc users most often try now that [Arc is shutting down on December 22, 2026](/docs/arc-shutdown/). Both are Chromium browsers that leave generative AI out. The difference is philosophy: Vivaldi gives you a setting for almost everything, Flecha copies Arc's sidebar and stops there.

## At a glance

| | Flecha | Vivaldi |
| --- | --- | --- |
| Made by | OPrimoDev | Vivaldi Technologies |
| Engine | Chromium | Chromium |
| Platforms | macOS 13+ (Apple silicon and Intel) | macOS 13+, Windows, Linux, Android, iOS ([download](https://vivaldi.com/download/)) |
| Vertical tabs | Arc-style sidebar, always | Tab bar on any side of the window ([help](https://help.vivaldi.com/desktop/tabs/tab-bar/)) |
| Spaces | Spaces, with separate cookies and logins by default | [Workspaces](https://vivaldi.com/features/workspaces/) |
| Pinned tabs that return to their address, Today tabs that archive | Yes | No |
| Peek and Little Arc | Peek and Flechinha | No |
| Split view | Two panes | [Tab tiling](https://help.vivaldi.com/article/tab-tiling/), several pages |
| Extensions | Chrome Web Store | Chrome Web Store |
| Google sign-in | Yes | Yes |
| Ad and tracker blocking | Built in | Built in |
| Built-in AI | None | None, on purpose ([Vivaldi 7.8](https://vivaldi.com/blog/vivaldi-7-8-launches-with-message-to-big-tech-humans-dont-need-ai-babysitters/)) |
| Built-in mail client | No | Yes |
| Source | Open source, MIT | Chromium changes public, interface closed |
| Price | Free | Free |
| Netflix and other Widevine DRM | No; offers to open the page in Safari | Yes ([help](https://help.vivaldi.com/desktop/media/widevinecdm-eme-drm-netflix-amazon-spotify/)) |
| Account and sync | No account, no sync | Optional account, end-to-end encrypted sync |
| Imports Arc's Spaces | Yes, with pinned tabs, folders and favorites | No Arc importer we could find |

## Choose Vivaldi if

- you need Windows, Linux or a phone app, or sync between devices,
- you watch Netflix, Disney+ or Spotify in the browser,
- you like to tune every detail, from tab stacks to where the tab bar sits, and want your mail in the same window.

## Choose Flecha if

- you want Arc's sidebar as it was: favorites, pinned tabs that go back to where they started, Today tabs that archive themselves, Peek and Flechinha,
- you want your Arc Spaces, pinned tabs and folders [brought over in one step](/docs/switch-from-arc/),
- you'd rather have fewer settings and no account,
- you build websites and want a [developer command bar](/docs/command-bar/) and a [built-in MCP server](/docs/agents/mcp/) for coding agents.

Ready to try? [Download Flecha](https://flecha.dev/#download) and [import your Arc sidebar](/docs/switch-from-arc/). Still deciding? See [all the Arc alternatives](/docs/compare/arc-alternatives/).
