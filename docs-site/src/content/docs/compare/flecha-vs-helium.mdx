[Helium](https://helium.computer/) is an open-source Chromium browser that strips out Google's services and blocks ads by default. It's still in beta, and it appeals to the same people Flecha does: those who want Chromium without the extras. Helium is a lean, general-purpose browser for every desktop OS; Flecha is built around Arc's sidebar and runs on Macs.

## At a glance

| | Flecha | Helium |
| --- | --- | --- |
| Made by | OPrimoDev | imput |
| Engine | Chromium | Chromium, with Google service dependencies removed |
| Platforms | macOS 13+ (Apple silicon and Intel) | macOS, Windows, Linux, in beta; no mobile ([Helium](https://helium.computer/)) |
| Vertical tabs | Arc-style sidebar, always | Vertical tabs |
| Spaces | Spaces, with separate cookies and logins by default | Not on Helium's feature list |
| Pinned tabs that return to their address, Today tabs that archive | Yes | No |
| Peek and Little Arc | Peek and Flechinha | No |
| Split view | Two panes | Yes |
| Extensions | Chrome Web Store | Chromium extensions, with Chrome Web Store requests anonymized |
| Ad and tracker blocking | Built in (EasyList, EasyPrivacy) | Built in: ads, trackers, cookie banners and third-party cookies |
| Built-in AI | None | None |
| Source | Open source, MIT | Open source, GPL-3.0 ([GitHub](https://github.com/imputnet/helium)) |
| Price | Free | Free |
| Netflix and other Widevine DRM | No; offers to open the page in Safari | No ([Helium](https://helium.computer/)) |
| Account and sync | No account, no sync | No sync yet |
| Imports Arc's Spaces | Yes, with pinned tabs, folders and favorites | Imports from your current browser; Arc's Spaces aren't mentioned |

## Choose Helium if

- you need Windows or Linux,
- you want Chromium with as little Google in it as possible,
- you want a plain browser with a normal tab layout and strong blocking defaults.

## Choose Flecha if

- you want Arc's sidebar: favorites, Spaces with their own logins, pinned tabs with folders, Today tabs that archive themselves, Peek and Flechinha,
- you want your Arc Spaces [imported in one step](/docs/switch-from-arc/),
- you want Air Traffic Control, Boosts and a command bar that understands `gh`, `npm` and `mdn`,
- you use coding agents and want them to see your real tabs through [MCP](/docs/agents/mcp/).

Neither plays Netflix or other Widevine-protected streaming today. Flecha offers to open those pages in Safari.

Ready to try? [Download Flecha](https://flecha.dev/#download) and [import your Arc sidebar](/docs/switch-from-arc/). Still deciding? See [all the Arc alternatives](/docs/compare/arc-alternatives/).
