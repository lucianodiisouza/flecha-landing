[Dia](https://www.diabrowser.com/) is The Browser Company's AI browser, and where it directs Arc users now that [Arc is sunsetting](https://arc.net/). Flecha is an open-source browser that keeps Arc's interface. They answer different questions: Dia puts an AI assistant in the browser, Flecha keeps the browser simple and lets your own coding agent in when you ask.

## At a glance

| | Flecha | Dia |
| --- | --- | --- |
| Made by | OPrimoDev | The Browser Company (Atlassian) |
| Engine | Chromium | Chromium |
| Source | Open source, MIT | Closed source |
| Platforms | macOS | macOS, Windows |
| Price | Free | Free; AI features on paid plans ([pricing](https://www.diabrowser.com/pricing)) |
| Account | None | Needed for sync and AI |
| Sidebar | Always, Arc-style | Optional layout |
| Spaces | Spaces, optionally with separate cookies | Profiles |
| Peek | Yes | No |
| Boosts | Yes | No |
| Built-in AI assistant | No | Yes |
| External coding agents | [Built-in MCP server](/docs/agents/mcp/) | No |
| Imports Arc | Spaces, pinned tabs, folders, favorites, history | Spaces as Profiles, folders as tab groups, passwords, history, extensions |
| Sync | No | End-to-end encrypted |

## Choose Dia if

- you want an AI assistant that reads and acts on your tabs, built into the browser,
- you need Windows, or sync between computers,
- you want your passwords imported from Arc.

## Choose Flecha if

- you want Arc's sidebar, Peek and Boosts as they were,
- you'd rather have no account and nothing about you leave your Mac,
- you write code and want a [command bar](/docs/command-bar/) that understands `gh` and `npm`, one key between local, staging and production, and your dev servers in the sidebar,
- you already use Claude Code or Cursor and want them to see your real browser through [MCP](/docs/agents/mcp/),
- you want a browser that can't be discontinued: the code is public.

Ready to try? [Install Flecha](/docs/install/) and [import your Arc sidebar](/docs/switch-from-arc/).
