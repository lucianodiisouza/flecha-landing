[Microsoft Edge](https://www.microsoft.com/edge) had vertical tabs years before most browsers, and it runs on the same Chromium engine as Arc. For people leaving Arc it's the familiar, well-supported choice. Flecha is the smaller, open-source one that keeps Arc's sidebar exactly as Arc users know it.

## At a glance

| | Flecha | Edge |
| --- | --- | --- |
| Made by | OPrimoDev | Microsoft |
| Engine | Chromium | Chromium |
| Platforms | macOS 13+ (Apple silicon and Intel) | macOS 13+ ([Microsoft](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-supported-operating-systems)), Windows, Linux, Android, iOS |
| Vertical tabs | Arc-style sidebar, always | Optional vertical tabs panel ([Microsoft](https://www.microsoft.com/en-us/edge/learning-center/how-to-multitask-like-a-pro)) |
| Spaces | Spaces, with separate cookies and logins by default | Workspaces (sets of tabs in their own window) and profiles |
| Pinned tabs that return to their address, Today tabs that archive | Yes | No |
| Peek and Little Arc | Peek and Flechinha | No |
| Split view | Two panes | Split screen, two tabs in one window |
| Extensions | Chrome Web Store | Edge Add-ons, and the Chrome Web Store |
| Google sign-in | Yes | Yes |
| Ad and tracker blocking | Built in (EasyList, EasyPrivacy) | Tracking prevention built in; ads need an extension |
| Built-in AI | None | Copilot, with features you can turn off ([Microsoft](https://blogs.windows.com/msedgedev/2026/05/13/new-updates-to-edge-across-desktop-and-mobile/)) |
| Source | Open source, MIT | Closed source on top of Chromium |
| Price | Free | Free |
| Netflix and other Widevine DRM | No; offers to open the page in Safari | Yes; Netflix lists Edge as supported on Mac ([Netflix](https://help.netflix.com/en/node/23742)) |
| Account and sync | No account, no sync | Optional Microsoft account for sync |
| Imports Arc's Spaces | Yes, with pinned tabs, folders and favorites | No Arc importer we could find |

## Choose Edge if

- you need Windows, Linux, a phone app or sync with a Microsoft account,
- you watch Netflix, Disney+ or Spotify in the browser,
- you want Copilot in the browser, or your company manages Edge for you.

## Choose Flecha if

- you want Arc's sidebar: favorites, pinned tabs with folders, Today tabs that archive themselves, Peek and Flechinha,
- you want your Arc Spaces [imported in one step](/docs/switch-from-arc/),
- you'd rather have no account, no telemetry and no AI built in,
- you build websites and want a [developer command bar](/docs/command-bar/) and a [built-in MCP server](/docs/agents/mcp/).

Ready to try? [Download Flecha](https://flecha.dev/#download) and [import your Arc sidebar](/docs/switch-from-arc/). Still deciding? See [all the Arc alternatives](/docs/compare/arc-alternatives/).
