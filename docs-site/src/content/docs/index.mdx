Flecha is a free, open-source Chromium browser for macOS, made for people who write code. It has a vertical sidebar with Spaces, a command bar that understands developer shortcuts, and an MCP bridge that lets your coding agent see and drive your tabs. There is no account and no telemetry: everything stays on your Mac.
