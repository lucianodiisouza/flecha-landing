⌥⌘B

              
Boosts: your own code on any site.

              
A Boost is a plain TypeScript or CSS file in ~/.flecha/boosts, named after the site. Flecha compiles it with esbuild. CSS applies live as you save, scripts reload the page. Keep the folder in git and your tweaks follow you to every Mac.

            

            

              
~/.flecha/boosts/

              
// github.com.ts · runs on every github.com page
export {};

const lockfiles = document.querySelectorAll<HTMLElement>(
  '[data-path$=".lock"]',
);
for (const file of lockfiles) file.hidden = true;

              
/* all.css · every site, applied live */
:root { font-synthesis: none; }
::selection { background: #3aa6d9; }

            

          


          

            

              
MCP · Model Context Protocol

              
Let your coding agent see and drive your tabs.

              
Turn on the bridge in Settings and Flecha serves MCP on 127.0.0.1, behind a token. Claude Code, Cursor and other agents can list tabs, read pages and console logs, take screenshots, click, type and run JavaScript. The sidebar shows what the agent is doing while it works.

Under the hood

          
Real Chromium, not a wrapper.

          
Flecha is a Chromium fork. Pages render exactly as they do in Chrome, Google sign-in works, and every extension from the Chrome Web Store installs, including content blockers and password managers that talk to their desktop app.

          
The fork stays small on purpose: a short list of patches for the window, sidebar panel, shortcuts, Peek and Flechinha. Everything you see is a built-in TypeScript extension, so updating Chromium stays easy.

        

        
      

    


    
    

      

        

          

            
Privacy

            
Local by design. Flecha collects nothing.

          

          
There is no account and nowhere for your data to go. Flecha only talks to flecha.dev to check for updates. Don't take our word for it: the code is public. Read the privacy policy.

        

        
        

          

            
Sent to Flechabytes

            
    
              
  • Usage analytics0
    • 
              
  • Crash reports0
    • 
              
  • Browsing history0
    • 
              
  • Account or sign-innone
    • 
            

            
Network traffic is the sites you open, your search engine, updates for extensions and blocker lists, update checks against flecha.dev, and the services built into Chromium itself.

          

          
    
            
  • 
              
    Your data is files on your Mac
    
              
    Tabs, Spaces, history and settings live in your Flecha profile. Back them up, delete them or move them to a new Mac.
    
            
    • 
            
  • 
              
    Trackers blocked out of the box
    
              
    Ad and tracker blocking is built in and on by default, with EasyList, EasyPrivacy and uBlock lists.
    
            
    • 
            
  • 
              
    Agents only when you say so
    
              
    The MCP bridge is off until you turn it on, listens only on 127.0.0.1 and needs a token. You see every action in the sidebar.
    
            
    • 
            
  • 
              
    Spaces can keep secrets
    
              
    Give a Space its own cookie jar and its sessions stay invisible to your other Spaces.
