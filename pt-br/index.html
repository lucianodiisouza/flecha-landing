Ferramentas de dev

            
A parte do seu dia que acontece no navegador.

          

          
Feito para o ciclo de editar, recarregar, conferir staging, perguntar ao agente e subir.

        


        

          

            

              
⌥⌘E

              
Uma tecla entre local, staging e produção.

              
Agrupe as origens de um projeto uma vez nas Configurações. A mesma página abre no próximo ambiente com caminho e query intactos, e a barra de endereço mostra um selo LOCAL, STAGING ou PROD para você nunca mexer em produção sem querer.

            

            

              
locallocalhost:3000/checkout?step=2⌥⌘E

              
stagingstaging.acme.dev/checkout?step=2⌥⌘E

              
prodacme.com/checkout?step=2⌥⌘E

⌥⌘B

              
Boosts: seu código em qualquer site.

              
Um Boost é o seu próprio TypeScript ou CSS para um site, com o nome dele: github.com.ts, github.com.css, ou all.css para todos os sites. Edite na página de Boosts do Flecha e aperte ⌘S: o CSS aplica ao vivo e os scripts recarregam as abas do site. Os Boosts ficam salvos no seu perfil do Flecha.

MCP · Model Context Protocol

              
Deixe seu agente de código ver e usar suas abas.

              
Ligue a ponte nas Configurações e o Flecha serve MCP em 127.0.0.1, protegido por token. Claude Code, Cursor e outros agentes listam abas, leem páginas e logs do console, tiram screenshots, clicam, digitam e rodam JavaScript. A sidebar mostra o que o agente está fazendo enquanto ele trabalha.

Por baixo do capô

          
Chromium de verdade, não um wrapper.

          
O Flecha é um fork do Chromium. As páginas renderizam igual ao Chrome, o login do Google funciona e qualquer extensão da Chrome Web Store instala, inclusive bloqueadores de conteúdo e gerenciadores de senha que conversam com o app do desktop.

          
O fork é pequeno de propósito: uma lista curta de patches para a janela, o painel da sidebar, os atalhos, o Peek e o Flechinha. Tudo o que você vê é uma extensão embutida em TypeScript, então atualizar o Chromium continua fácil.

        

        
      

    


    
    

      

        

          

            
Privacidade

            
Local por design. O Flecha não coleta nada.

          

          
Não existe conta nem para onde seus dados irem. O Flecha só fala com o flecha.dev para checar atualizações. Não precisa acreditar na gente: o código é público. Leia a política de privacidade.
