Uma tecla entre local, staging e produção.

⌥⌘B

              
Boosts: seu código em qualquer site.

              
Um Boost é um arquivo TypeScript ou CSS comum em ~/.flecha/boosts, com o nome do site. O Flecha compila com esbuild. O CSS aplica ao vivo quando você salva, scripts recarregam a página. Coloque a pasta no git e seus ajustes vão junto para qualquer Mac.

            

            

              
~/.flecha/boosts/

              
// github.com.ts · roda em toda página do github.com
export {};

const lockfiles = document.querySelectorAll<HTMLElement>(
  '[data-path$=".lock"]',
);
for (const file of lockfiles) file.hidden = true;

              
/* all.css · todos os sites, aplicado ao vivo */
:root { font-synthesis: none; }
::selection { background: #3aa6d9; }

Deixe seu agente de código ver e usar suas abas.

Por baixo do capô

          
Chromium de verdade, não um wrapper.

          
O Flecha é um fork do Chromium. As páginas renderizam igual ao Chrome, o login do Google funciona e qualquer extensão da Chrome Web Store instala, inclusive bloqueadores de conteúdo e gerenciadores de senha que conversam com o app do desktop.

          
O fork é pequeno de propósito: uma lista curta de patches para a janela, o painel da sidebar, os atalhos, o Peek e o Flechinha. Tudo o que você vê é uma extensão embutida em TypeScript, então atualizar o Chromium continua fácil.

        

        
      

    


    
    

      

        

          

            
Privacidade

            
Local por design. O Flecha não coleta nada.

          

          
Não existe servidor do Flecha para onde mandar seus dados. Não precisa acreditar na gente: o código é público. Leia a política de privacidade.

  • 
              
    Seus dados são arquivos no seu Mac
    
              
    Abas, Spaces, histórico e configurações ficam no seu perfil do Flecha. Faça backup, apague ou leve para um Mac novo.
    
            
    • 
            
  • 
              
    Rastreadores bloqueados de fábrica
    
              
    O bloqueio de anúncios e rastreadores vem embutido e ligado por padrão, com as listas EasyList, EasyPrivacy e uBlock.
    
            
    • 
            
  • 
              
    Agentes só quando você deixa
    
              
    A ponte MCP fica desligada até você ligar, só escuta em 127.0.0.1 e exige token. Você vê cada ação na sidebar.
    
            
    • 
            
  • 
              
    Spaces guardam segredos
    
              
    Dê a um Space seu próprio pote de cookies e as sessões dele ficam invisíveis para os outros Spaces.

Migrando

          
Traga tudo com você. Inclusive do Arc.
